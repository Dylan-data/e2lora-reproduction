# 给 Codex 的任务：文本生成实验

你是负责 E²LoRA 文本生成复现的成员的 Codex。负责论文表 2、14、15，以及分工中分给文本生成的梯度图。先从表 2 的数学任务做起，再做代码。常识、扩展模型和额外图表分别排期。读取仓库根目录 README、`references/text-generation-setup.json`、Word 报告、模型和数据清单，以及 `experiments/dylan/generation_parameter_check.py`。先确认我认领的目录，建议沿用 `experiments/chloe/`，如果团队已约定别的目录，遵循约定。

## 现有设置和缺项

- 主模型是 Llama 3.1 8B Base。现有配置记录了权重版本、注意力投影、AdamW、学习率 5e-5、总批量 64、BF16、余弦调度和各基线的学习率例外。正文用 3% warmup，表 9 写 0.3 且另列 LR Decay 0.1。先用正文的 3%，记录余弦调度的最低学习率和对 0.1 的处理。任何替代设置先写理由。
- 现有参数量检查记录每种投影总秩 256、更新 139 个分量，E²ShareLoRA 冻结全局共享的 A。两方法测得约 3.701M 和 1.423M。把它们作为团队的复现选择和试跑核对值，分别与论文表 2 比较。这个检查只用少量样本，没有完成生成训练。
- 数学用 MetaMathQA 的 100,000 条训练样本，固定来源版本、抽样种子和样本编号，GSM8K test 用于最终评分。代码按团队决定使用公开 Code-Feedback train 约 66,400 条，记录实际读入条数和版本，报告说明论文用了 100,000 条 code-only 样本。HumanEval 用于最终评分。若配置仍写 null，以这一决定为准。确认 Llama 授权和本地权重可读；需要许可时直接告诉我需要操作的页面。
- 训练轮数在独立验证集上看分数走势。先统计分词后的长度和答案截断率，再选最大训练长度。用短跑测峰值显存，按「卡数 × 每卡批量 × 梯度累积」凑到 64。写明每轮更新步数和最后一批的处理。论文用于代理熵诊断的 1024 步属于另一项实验。
- 固定数学与代码的训练模板、训练时哪些 token 计算损失、评估提示、最大生成长度和解码方式。用验证样本检查截断和判分。GSM8K 提取最终数字并比较答案。HumanEval 保留原题提示，每题生成一次，用测试判断通过比例。运行模型生成的代码应使用无网络、无凭据、有时间限制的隔离环境。

## 实现和试跑

在认领目录放训练入口、评测入口、配置和 README。训练入口应接受模型、任务、方法、种子和输出位置，加载新权重、接上适配矩阵、训练、保存可恢复的状态。评分入口读取该次训练的产物并写出结果。通用数据和评分逻辑放进 `src/e2lora/` 对应模块，供消融成员使用。先用同一批数学样本跑 LoRA 与 E²LoRA，再验证代码任务。成功信号是两方法都能更新权重、从保存点恢复、生成可判分的输出，参数统计和训练配置可追溯。与消融成员共享数学训练样本清单和评分配置。

1. **盘点。** 先查 `git status`、最新提交、报告和已有结果，保留其他成员的改动。用表格列出每组对应论文表图、输入来源、方法、指标、种子、依赖、优先级、显卡及单次估时。用试跑实测校准估时。标出哪些设置已确认、哪些是团队选择、哪些仍缺信息。
2. **准备。** 从 `src/e2lora/model/LIST.md` 和 `src/e2lora/dataset/LIST.md` 核对版本与访问条件，检查文件齐全、磁盘与显存可用。先读 `src/e2lora/model/pretrained.py`、`src/e2lora/dataset/loading.py`、`src/e2lora/adapters/adaptive.py`、`src/e2lora/adapters/lora_layers.py`，复用合适的加载、梯度、分组和共享实现。复现代码按论文自行实现。共用接口需要改动时，与受影响成员核对。
3. **小规模验收。** 提供一条可重复的试跑命令。固定配置和种子，核对数据划分、参数计数、评分、耗时、峰值显存和中断恢复。把试跑标明为试跑。共享权重只计一次，分别记录适配参数和总可训练参数。遇到分秩报错，记录样本和组代表值，先核对统一处理方式。
4. **完整实验开跑条件。** 模型和数据版本已固定，训练和评分都经过小样本检查，参数量和评估口径可解释，资源和排期已核实，每组配置和输出路径已确定。先把计划、试跑证据和仍需我决定的事项发给我。我确认后再提交完整训练。提交后记录作业号，每个方法或可安全续跑的小批次独立保存，收回结果时及时报告失败或与论文差距明显的项目。
